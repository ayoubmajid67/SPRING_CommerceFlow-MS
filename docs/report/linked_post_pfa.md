🚀 **PFA Project Update — SPRING_CommerceFlow-MS at ~80% Completion!**

Together with **Ayoub Majjid**, under the supervision of **Prof. Hatim JAADOUNI**, we've been building **SPRING_CommerceFlow-MS** — an e-commerce platform based on a **microservices architecture** using **Spring Boot** and **Spring Cloud**.

> 📌 This is just our current milestone — the project continues until 100% completion!

---

### ✅ **What We've Accomplished (~80%):**

- ✅ **4 Microservices:** Product, Order, Inventory + API Gateway
- ✅ **Polyglot Persistence:** MongoDB + MySQL
- ✅ **Eureka Service Discovery** + Client-Side Load Balancing
- ✅ **OAuth2/OIDC Security** with Keycloak (JWT)
- ✅ **Resilience4j:** Circuit Breaker, Retry, TimeLimiter
- ✅ **Dockerized** infrastructure
- ✅ **Testing:** Unit, Integration & E2E tests
- ✅ **Simple Angular UI** to demonstrate the architecture (back-end focused!)
